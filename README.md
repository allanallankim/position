# 바른 · 업무 자세 코치

`design.md`의 첫 버전 방향을 구현한 브라우저 전용 MVP입니다. Node.js 20 이상에서 별도 패키지 설치 없이 실행합니다.

```powershell
npm.cmd start
```

브라우저에서 http://localhost:5173 을 열고 카메라를 허용하세요. 얼굴·귀·어깨·골반이 모두 보이도록 카메라를 배치하고 **기준 자세 등록**을 누르면, 유효하게 인식되는 20초 동안 개인 기준값을 수집합니다. 이후 점검을 진행하고 **세션 종료**를 누르면 리포트를 저장합니다. 모바일 카메라 사용에는 HTTPS 호스팅이 필요합니다. 일반 HTTP의 PC LAN IP 주소로는 카메라 권한을 사용할 수 없습니다.

## 구현 범위

### 휴대폰에서 외부 접속하기

```powershell
npm.cmd run mobile
```

이 명령은 공식 Cloudflare cloudflared 실행 파일을 `.tools`에 내려받고 GitHub 릴리스의 SHA256과 대조합니다. 로컬 서버가 없으면 시작하고, 임시 공개 HTTPS 주소를 생성합니다. 출력된 **https://…trycloudflare.com** 주소를 휴대폰 Safari/Chrome의 주소창에서 직접 열고 카메라 권한을 허용하세요. HTTP IP 주소와 Windows 전용 예외 스크립트는 휴대폰의 보안 제한을 해제하지 못합니다.

실행 중에는 PC와 터미널을 켜 두세요. Ctrl+C로 터널과 이 명령이 시작한 서버를 종료합니다. 이미 실행 중이던 서버는 유지합니다. 포트 포워딩과 자체 서명 인증서는 필요하지 않습니다. 주소를 아는 사람은 앱에 접속할 수 있지만 카메라 영상과 자세 기록은 각 접속자의 브라우저에서만 처리됩니다. 임시 주소는 재실행 시 바뀌며, 주소가 바뀌면 브라우저의 기준 자세와 기록도 별개로 저장됩니다. 이 터널은 개발/체험용입니다. 고정 운영 주소는 도메인에 유효한 HTTPS 인증서를 적용하거나 정식 호스팅을 사용하세요.

HTTPS에서도 권한 오류가 나면: Safari/Chrome에서 직접 열었는지, 사이트별 카메라 권한 및 휴대폰 설정의 브라우저 카메라 권한이 허용되었는지 확인하세요. 앱 내장 브라우저나 iframe 미리보기에서는 차단될 수 있습니다.

공식 안내: https://developers.cloudflare.com/tunnel/get-started/quick-tunnels/

### HTTP 주소에서 카메라 사용하기 (Windows 개발용)

localhost는 HTTPS 없이도 카메라를 사용할 수 있습니다. LAN IP 등 다른 HTTP 주소는 브라우저의 개별 예외 설정이 필요합니다. 서버를 실행한 상태에서 다음 명령으로 전용 Chrome/Edge 창을 여세요.

```powershell
# 같은 PC
powershell -ExecutionPolicy Bypass -File .\open-http-camera.ps1

# LAN 주소 사용: 실제 서버 주소로 변경
powershell -ExecutionPolicy Bypass -File .\open-http-camera.ps1 -Url "http://192.168.0.10:5173"
```

카메라 권한은 이 창에서도 직접 허용해야 합니다. 스크립트는 지정한 주소(origin)만 개발용 보안 예외로 등록하고 `.http-camera-profile` 아래 별도 브라우저 프로필을 사용합니다. 기존 브라우저 설정은 변경하지 않습니다. 이 창에서는 해당 개발 앱만 사용하세요. HTTP 통신 자체는 암호화되지 않습니다. 다른 PC에서는 해당 PC에서 스크립트를 실행해야 하며 모바일에는 적용되지 않습니다. 조직 정책이 브라우저 옵션을 금지한 환경에서는 HTTPS를 사용해야 합니다.

공식 설명: https://new.chromium.org/Home/chromium-security/deprecating-powerful-features-on-insecure-origins/

- MediaPipe 33개 랜드마크 추정, 영상과 스켈레톤의 좌우 반전 정렬
- 기준 등록 전에도 일반 수평·수직 정렬 대비 참고 점수를 즉시 표시합니다. 개인 기준 등록 후에는 개인 기준 대비 점수로 전환합니다. 목 깊이는 개인 기준이 있어야 평가합니다.
- 골반·귀가 보이지 않아도 양쪽 어깨가 인식되면 가능한 항목을 계속 계산합니다. 미인식 항목은 점수에서 제외하고 항목 수와 제외 사유를 표시합니다. 분석 항목 수/기준이 바뀌면 점수의 비교 조건도 달라집니다.
- 개인 기준 대비 목 전방 이동 참고값, 어깨·상체·고개 기울기, 자세 점수
- 관절 신뢰도 검사, 20초 유효 인식 기준 자세 등록 및 브라우저 저장
- 5초 지속 시 교정 피드백, 문제별 발생 횟수, 하루 알림 상한, 집중 모드
- 25분 리셋 안내, 1분 목·어깨 리셋 타이머
- 세션 평균, 10분/1시간 구간 리포트, 최근 7일 추이, JSON 내보내기 및 기록 삭제
- 카메라 권한·장치·모델 로딩 오류 처리, 세션 종료 시 카메라 해제

영상 및 관절 좌표는 서버로 보내거나 저장하지 않습니다. 기준 지표·설정·최근 200개 세션 통계만 localStorage에 저장합니다. 브라우저/기기가 다르면 기록도 별개입니다. 알림 발생 횟수는 교정 상태가 회복된 뒤 다시 5초 지속할 때 새로 집계합니다. 알림 상한은 시스템 알림을 제한하며 화면 피드백과 리포트 집계는 계속됩니다.

로그인, 계정 동기화, Node/PostgreSQL 백엔드, 운동별 자세 분석, 정확한 라운드 숄더 판정은 이번 MVP에 포함하지 않았습니다. 정면 카메라의 깊이 정보는 불안정할 수 있어 목 지표는 어깨 폭으로 정규화한 개인 기준 대비 추정값이며 cm로 표시하지 않습니다. 점수는 간단한 휴리스틱이며 의료/임상적으로 검증된 측정값이 아닙니다. 카메라 위치가 바뀌면 기준을 다시 등록하세요.

## 검증

```powershell
npm.cmd test
npm.cmd run check
```

기하 계산, 화면 비율 보정, 신뢰도 제외, 기준 평균, 점수, 5초 알림의 재진입을 Node 내장 테스트로 검증합니다. 실제 카메라·GPU·권한 및 시스템 알림은 사용하는 브라우저에서 확인해야 합니다.

모델과 WASM은 첫 카메라 시작 시 인터넷에서 불러옵니다. MediaPipe 0.10.21를 고정했으며 Google Fonts도 외부에서 요청합니다. 네트워크 차단 환경에서는 정적 자산을 내려받아 경로를 변경해야 합니다.

공식 API: https://ai.google.dev/edge/mediapipe/solutions/vision/pose_landmarker/web_js — 웹에서는 `LIVE_STREAM` 대신 `VIDEO`와 `detectForVideo`를 사용합니다. 추론은 10 FPS로 제한하며 현재 MVP는 메인 스레드에서 실행합니다. 저사양 기기 성능이 부족하면 후속 단계에서 Worker 추론으로 이전할 수 있습니다.
